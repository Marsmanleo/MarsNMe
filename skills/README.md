# Skills (Public Templates)
This directory contains optional prompt/rule templates for different AI clients.

## Goals
- Provide a consistent daily boot flow for memory MCP usage.
- Keep templates generic and reusable across teams.
- Avoid hardcoded personal names, device names, or private workflow terms.

## Structure
- `perplexity/memory-daily-boot/SKILL.md`
- `cursor/memory-daily-boot/rule.mdc`
- `warp/memory-daily-boot/prompt.md`

## Placeholder conventions
Use these placeholders in public templates:
- `your-name`
- `your-agent-name`
- `your-client`
- `profile-a` / `profile-b`

## Versioning
When you update one template, review and update the other platform variants to keep behavior aligned.
