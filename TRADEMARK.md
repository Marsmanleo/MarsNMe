# Trademark Policy
This document describes how names and marks related to MarsNMe may be used.

## Protected names
The following names are marks owned or controlled by Mars Group:
- CoCo
- MarsVault
- Mars Group
- MarsNMe

## Allowed use
You may use these names in truthful, descriptive references, for example:
- “Built on mars-memory-mcp”
- “Compatible with MarsNMe MCP gateway”
- “Based on Apache-2.0 licensed code from this repository”

## Not allowed without written permission
- Using any protected name as your product name, company name, logo, or domain in a way that implies endorsement
- Presenting forks or modified versions as an official Mars Group release
- Using confusingly similar marks, logos, or branding

## Source code license vs trademark rights
The Apache-2.0 license grants software rights to use, modify, and distribute code.
It does not grant trademark rights.

## Requests
For trademark or brand usage requests, contact Mars Group maintainers through repository issues first.
